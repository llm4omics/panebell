Built for long-running terminal & AI workflows

No background web server, no database ports, and no LLM polling loops.

Independent tmux Views

Reuses matching windows or opens an isolated client view (pb-view-…) so side-by-side windows inspect different panes of the same session without switching each other.

Durable SQLite Receipts

Transient desktop banners vanish. Explicit completions persist in events.sqlite3 on the host until marked as read, syncing offline acknowledgements on reconnect.

Honest Lifecycle States

Closing a waiting pane hides its stale request instead of inventing a fake completion. Replayed notifications with the same run ID deduplicate cleanly.

Observe-Only AI Hooks

Surfaces Claude Code PermissionRequest prompts and Codex turn completions. PaneBell jumps to your runner—it never auto-grants permissions or stores tool inputs.
